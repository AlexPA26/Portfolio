00 / PREPARA EL TERRENO

Una librería, muchas posibilidades

Day.js facilita trabajar con fechas mediante métodos encadenables. dayjs() crea un objeto con la fecha y hora actuales; format() lo convierte en texto.

Este HTML ya carga la librería, el idioma español y dos plugins por CDN. Ábrelo directamente en tu navegador con conexión a Internet, sin instalar nada.

Ver cómo se conecta todo 
<!-- Dentro del HTML, en este orden -->
<script defer src="https://cdn.jsdelivr.net/npm/dayjs@1.11.13/dayjs.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/dayjs@1.11.13/locale/es.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/dayjs@1.11.13/plugin/customParseFormat.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/dayjs@1.11.13/plugin/relativeTime.js"></script>
<script defer src="indexDayjs.js"></script>

// Al principio de indexDayjs.js:
dayjs.extend(window.dayjs_plugin_customParseFormat);
dayjs.extend(window.dayjs_plugin_relativeTime);
dayjs.locale('es');
const ahora = dayjs();
const fecha = dayjs('2026-09-29');
const desdeDate = dayjs(new Date());
console.log(fecha.format('DD/MM/YYYY')); // 29/09/2026

Los ejemplos usan la hora local de tu navegador. Cambiar el idioma modifica los nombres de meses y días, pero no la zona horaria.

01 / DAR FORMA

La misma fecha, a tu manera

format() sustituye los tokens por partes de la fecha. Escribe texto literal entre corchetes, por ejemplo [Hoy es] dddd.

Tokens que usarás a menudo
Token Significado Ejemplo
YYYY Año completo 2026
MM / MMMM Mes numérico / nombre 09 / septiembre
DD / dddd Día del mes / de la semana 29 / martes
HH / mm / ss Hora / minutos / segundos 17 / 30 / 00

¡Las mayúsculas importan! MM es el mes y mm son los minutos.

02 / MOVERSE EN EL TIEMPO

Suma, resta y conserva el original

add() y subtract() devuelven un nuevo objeto. Day.js es inmutable: debes guardar el resultado si quieres utilizar la fecha modificada.

Prueba 31 de enero + 1 mes: se ajusta al último día de febrero. También puedes usar fecha.startOf('month') y fecha.endOf('month') para obtener los límites del mes.

03 / PONER FECHAS EN PERSPECTIVA

¿Cuánto tiempo hay entre dos días?

fin.diff(inicio, 'day') calcula la diferencia. El resultado es negativo si el final está antes del inicio. Por defecto, diff() devuelve un entero; un tercer argumento true permite decimales.

El segundo argumento de isSame(), isBefore() e isAfter() controla la precisión. Con 'day' comparas días sin tener en cuenta la hora.

04 / COMPROBAR ANTES DE USAR

No todas las fechas existen

El plugin customParseFormat permite interpretar un formato concreto. Con true activas la validación estricta: el día debe existir y el texto debe coincidir exactamente con el formato.

Sin validación estricta, algunas fechas desbordadas se normalizan a otro mes. Prueba 29/02/2024 y 29/02/2025 para explorar los años bisiestos.

05 / HABLAR COMO UNA PERSONA

«Hace dos días» suena mejor

El plugin relativeTime añade fromNow(). Devuelve una descripción aproximada respecto al momento actual, usando el idioma configurado.

fromNow(true) elimina el prefijo o sufijo: «2 días». Para comparar con una fecha concreta en lugar de ahora, utiliza fecha.from(otraFecha).

06 / TU TURNO

Programa el próximo recordatorio

Partiendo del 29 de septiembre de 2026, suma 7 días y muestra el resultado como 06/10/2026. Inténtalo en la consola del navegador (F12 → Consola).

Ver solución explicada 
const inicio = dayjs('2026-09-29');
const recordatorio = inicio.add(7, 'day');
console.log(recordatorio.format('DD/MM/YYYY')); // 06/10/2026

// También puedes encadenar los métodos:
dayjs('2026-09-29').add(7, 'day').format('DD/MM/YYYY');

add() devuelve otro objeto Day.js y por eso puedes llamar después a format(), que devuelve un string.
